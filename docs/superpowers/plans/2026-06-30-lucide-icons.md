# Lucide-style Flat Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the app's SF Symbols (in menu bar, popover, settings) and the macOS app icon with flat, uniform-stroke icons matching the Lucide aesthetic.

**Architecture:** A new `LucideIcon` type embeds each glyph's verbatim Lucide path data (`d` strings + `circle`/`rect` primitives) as Swift constants and renders them to template `NSImage`s via a tiny in-house path reader + Core Graphics. AppKit (status bar) consumes `NSImage` directly; SwiftUI views use a thin `LucideIconView` wrapper. The app icon is generated by a `Scripts/` script that draws the Lucide `activity` glyph on a graphite background and runs `iconutil`.

**Tech Stack:** Swift 5.9, AppKit, SwiftUI, Core Graphics, SwiftPM, `iconutil` (macOS).

## Global Constraints

- **No third-party dependencies.** Path data is embedded string constants; no SPM packages added.
- **No bundled asset files for in-app icons.** No `Bundle.module` / `.xcassets` / `.svg` / `.pdf` resources — `Makefile` resource handling must remain untouched for in-app icons.
- **Glyph subset:** the reader supports ONLY these SVG commands (all that the 8 icons use): `M m L l H h V v A a Z z`, plus `<circle cx cy r>` and `<rect x y width height rx>`. No cubic/quadratic béziers. All `A` arcs have rx==ry (circular).
- **All icons:** stroke-only, 24×24 viewBox, stroke-width 2, `.round` line cap + join, `fill = .none`.
- **Template images:** every produced `NSImage` has `isTemplate = true`.
- **No state-changing git commands** (project policy overrides the plan template's commit steps). Each task therefore ends with a build/test verification step instead of a commit. Staging/committing is the user's call.
- Platform floor: macOS 13 (`.macOS(.v13)` in `Package.swift`).

**(b) The path reader.** Implement `static func cgPath(fromElements:) -> CGPath` that builds a single `CGMutablePath` in SVG user space (origin top-left, y-down — we build in raw SVG coordinates and flip later at render time). Requirements:

- `circle` → `path.addEllipse(in: CGRect(x: cx-r, y: cy-r, width: 2r, height: 2r))`.
- `rect` → `path.addRoundedRect(in: CGRect(x:x,y:y,width:w,height:h), cornerWidth: rx, cornerHeight: rx)`.
- `path(d)` → tokenize and execute the `d` mini-language. Support commands `M m L l H h V v A a Z z`. Rules:
  - Numbers may be separated by spaces, commas, or sign (`-` starts a new number); a command letter may be followed by multiple coordinate sets that repeat the command (after `M`/`m`, subsequent pairs are implicit `L`/`l`).
  - Track `current` point and `subpathStart`. `Z/z` closes (`path.closeSubpath()`) and sets current to subpath start.
  - `H/h` and `V/v` change one axis only.
  - `A/a` parameters are `rx ry xAxisRotation largeArcFlag sweepFlag x y`. Because every icon uses `rx == ry` (circular) and `xAxisRotation == 0`, convert with the standard SVG endpoint→center arc algorithm (W3C SVG Implementation Notes, "Conversion from endpoint to center parameterization") and emit with `path.addArc(center:radius:startAngle:endAngle:clockwise:)`. Note the SVG `sweepFlag` semantics: `sweep==1` is positive-angle (in SVG's y-down space). Add a unit test if the visual arc direction looks wrong. Provide a helper:

```swift
private static func addSVGArc(to path: CGMutablePath, from p0: CGPoint,
                              rx: CGFloat, ry: CGFloat, largeArc: Bool,
                              sweep: Bool, to p1: CGPoint) {
    // rx == ry for all our icons; treat as circular radius r.
    let r = max(rx, ry)
    if r == 0 || p0 == p1 { path.addLine(to: p1); return }
    let mid = CGPoint(x: (p0.x - p1.x) / 2, y: (p0.y - p1.y) / 2)
    var rr = r
    // Ensure radius is large enough.
    let dsq = mid.x*mid.x + mid.y*mid.y
    if dsq > rr*rr { rr = sqrt(dsq) }
    // Center parameterization for circular arc.
    let sign: CGFloat = (largeArc != sweep) ? 1 : -1
    let num = max(rr*rr - dsq, 0)
    let coef = sign * sqrt(num / dsq)
    let cxp = coef * mid.y
    let cyp = -coef * mid.x
    let cx = cxp + (p0.x + p1.x) / 2
    let cy = cyp + (p0.y + p1.y) / 2
    let start = atan2(p0.y - cy, p0.x - cx)
    let end   = atan2(p1.y - cy, p1.x - cx)
    // In CGPath's coordinate space we draw before the y-flip, so `clockwise`
    // is the SVG sweep flag inverted (verify visually).
    path.addArc(center: CGPoint(x: cx, y: cy), radius: rr,
                startAngle: start, endAngle: end, clockwise: !sweep)
}
```

**(c) Rendering to a template NSImage:**

```swift
extension LucideIcon {
    /// Renders the glyph centered in a `pointSize` square as a template image.
    func image(pointSize: CGFloat, lineWidthScale: CGFloat = 1) -> NSImage {
        let viewBox: CGFloat = 24
        let strokeViewBox: CGFloat = 2 * lineWidthScale          // Lucide stroke-width
        let path = LucideIcon.cgPath(fromElements: elements)

        let image = NSImage(size: NSSize(width: pointSize, height: pointSize),
                            flipped: false) { _ in
            guard let ctx = NSGraphicsContext.current?.cgContext else { return false }
            // Inset by half the (scaled) stroke so the stroke isn't clipped.
            let scale = pointSize / viewBox
            let strokePts = strokeViewBox * scale
            let inset = strokePts / 2
            let drawScale = (pointSize - strokePts) / viewBox

            // Map SVG space (0..24, y-down) into the y-up image, with inset.
            ctx.translateBy(x: inset, y: pointSize - inset)
            ctx.scaleBy(x: drawScale, y: -drawScale)

            ctx.addPath(path)
            ctx.setLineWidth(strokeViewBox)          // in SVG units; scaled by ctx
            ctx.setLineCap(.round)
            ctx.setLineJoin(.round)
            ctx.setStrokeColor(NSColor.black.cgColor) // template: color is ignored
            ctx.strokePath()
            return true
        }
        image.isTemplate = true
        return image
    }
}
```
